# Oshi Motion Studio v0.1.0

**推しを組み立てる・動かす・眺めるための、独立した試作アプリです。**

`index.html` をブラウザーで開いて使用します。インターネット通信、外部ライブラリー、アカウント登録は不要です。サンプルとして、今回の赤髪キャラクター立ち絵と元のパーツシートを同梱しています（HTML内に埋め込み）。

## 最初に試す

1. 作品一覧から **「赤髪のサンプル」→「眺める」** を選ぶ。全身のゆっくりした呼吸・揺れを確認する。
2. **「編集に戻る」** を押す。キャラクターのパーツは、指でドラッグして位置を移動できる。
3. **「✂ パーツシート」** を開き、指で四角くなぞってパーツを選択する。小さな目は拡大ボタンで表示を拡大する。
4. **「このパーツを追加する」** を押す。右側（スマートフォンでは下側）のレイヤーからパーツを選び、位置・大きさ・役割を設定する。
5. **「♡ 鑑賞」** に移動すると、編集用の枠を隠してキャラクターを眺められる。

## 実装済み

- 複数キャラクターの作品管理、ローカル保存
- 透明PNGのパーツ取り込み（複数同時対応）
- パーツシート画像からの矩形切り出し・白背景の周辺連結領域の透過処理
- レイヤーのドラッグ、拡大縮小、回転、並べ替え、複製、ロック、非表示、左右反転、支点設定
- 編集画面での動作プレビュー、鑑賞モード、拡大、移動、背景変更、一時停止
- 全体の呼吸／ゆらぎ、髪／腕の揺れ
- 左右それぞれの目のパーツ登録と**左右同時の瞬き**（開眼・半目・閉眼に対応。差分がない場合は開眼パーツを上下に縮める）
- 口の開閉差分を利用した「おしゃべり風」の無音アニメーション
- 作品のJSONバックアップ・再読み込み、静止ポーズの透過PNG書き出し
- Character Atlas連携を想定したJSON書き出し（**Atlas側への読み込みは未実装**）

## 制約・未対応

- サンプルの全身立ち絵は**単一レイヤー**です。呼吸・揺れはすぐ試せますが、目の瞬きや口の動きには、目・口などの差分を登録して配置する必要があります。
- パーツシートは生成画像です。パーツ間で形が一致する保証はなく、調整・描き足しが必要な場合があります。
- このバージョンは**Live2D本体のファイルやリギングを直接読み書きしません**。Canvasで重ねる簡易2Dアニメーションです。
- 音声対話、リップシンク、録画動画／GIFの書き出し、Character Atlasへのワンクリック登録は未実装です。
- データはブラウザーのIndexedDB（利用できない場合はLocalStorage）に保存します。端末のストレージ整理、プライベートブラウズなどで削除され得るため、**JSONバックアップを書き出してください**。
- iPhoneの「ファイル」アプリでHTMLを直接開くと、プレビュー表示になりJavaScriptが動かない場合があります。その場合はSafariからアクセスできるWebサーバーまたは静的ホスティングに配置してください。公開リポジトリー等にアップロードすると、**HTMLに埋め込んだサンプル画像も公開される**ので注意してください。

## プライバシー

実装は外部APIや解析通信を呼びません。取り込んだ画像はユーザーのブラウザー内で処理し、保存／書き出し操作によって端末内に保持します。第三者サービスにアップロードする機能はありません。

## データ形式

- バックアップ：`*-backup.json` / format=`oshi-motion-studio-project`
- Atlas連携用：`*-atlas.json` / format=`oshi-motion-atlas-bridge`
- 連携用JSONの詳細は `atlas-bridge-spec.md` を参照
